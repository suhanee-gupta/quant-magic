# Quant Magic

A simple quantitative backtesting project for Indian equities using a long-only Markowitz mean-variance portfolio.

## Overview

This project downloads adjusted close prices from Yahoo Finance, builds a training-period optimal portfolio, and evaluates it against a benchmark index on a held-out test period.

## Project structure

- `quant_magic/` - reusable Python modules
- `tests/` - lightweight regression tests
- `results/` - output CSVs generated by the backtest
- `plots/` - charts generated from results

## Setup

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Dependencies

- numpy
- pandas
- scipy
- yfinance
- matplotlib

## Run the backtest

```bash
python -m quant_magic.main
```

## Example output

The script prints:

- portfolio weights
- CAGR
- Sharpe ratio
- max drawdown
- Calmar ratio
- win rate

## Notes

- This is a research prototype, not financial advice.
- The existing dataset uses Indian market tickers such as `RELIANCE.BO` and benchmark indices like `^BSESN`.
